## Changes by Kind

### Bug or Regression

- Fix Standard Load Balancer backend updates for Uniform VMSS to skip Nodes whose instance cannot be found, whose provider ID does not match the instance resolved from the Node name, or whose instance is outside CCM's configured resource group. Warning Node events will be emitted to explain these validation-related skips. ([#11235](https://github.com/kubernetes-sigs/cloud-provider-azure/pull/11235), [@Liunardy](https://github.com/Liunardy))
- Fix a panic when a route table is missing and resource tags are configured, while preserving creation and tagging of the missing table. ([#11268](https://github.com/kubernetes-sigs/cloud-provider-azure/pull/11268), [@Liunardy](https://github.com/Liunardy))
- Fix an issue where cloud provider attempts to re-create a NIC that is being deleted. ([#11267](https://github.com/kubernetes-sigs/cloud-provider-azure/pull/11267), [@matthchr](https://github.com/matthchr))
